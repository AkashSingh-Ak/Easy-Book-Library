# MASTER PROMPT

# Build a Production-Quality AI Powered Ebook Reader (FastAPI + Python)

## Objective

Develop a **production-quality, lightweight, web-based Ebook Reader** using **Python FastAPI**.

The application must run completely on a local machine and should be optimized for low RAM usage while remaining highly responsive.

The application is **not** a PDF viewer.

It is a complete ebook management and reading system supporting **PDF** and **EPUB** files while preserving the original formatting of the books.

The application should be modular, scalable, and designed for future AI integrations.

---

# Core Requirements

The application must support:

* PDF books
* EPUB books

Books are stored locally.

The application indexes all books into an internal library database.

The application should never modify the original book files.

Instead, it loads them dynamically while overlaying all reader features.

The original book remains unchanged.

# Book Import

The application must support multiple methods for importing books into the library, including:

* Drag & Drop
* File Picker
* Folder Import

Upon import, the application should automatically extract and index all available metadata from the book, including:

* Cover image
* Metadata
* Author
* Title
* Publisher
* ISBN (if available)

All extracted metadata must be stored in the SQLite database to enable efficient searching, filtering, sorting, and library management without modifying the original book files.
